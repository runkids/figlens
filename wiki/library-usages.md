# Library usages

Field reference linked from [usages](usages.md): how a stored generation keeps library references and how `usages` with `library` reads them across a workspace.

Library references (#93): a stored generation (`search::index_bytes` only) also keeps `uses_library` edges in `Record.library`, off `Record.edges`, so edge readers match builds that skip them (stateless, viewer, diff); never loaded back. The target is the JSON array `[kind, namespace, key]` (kind `component`, `style` or `variable`), so strings cannot collide. The namespace is `sourceLibraryKey` from a cached copy, basis `cached_copy`: a main's own copy (evidence `{"copy": id}`), or for a style or variable assetRef the copies carrying its key (evidence `{"field", "version"}`). References carry no namespace, and a file's own definitions carry no key (keys are server-assigned), so this proves no definition identity. No namespace, no copy or disagreeing copies give `namespace: null`, state `unresolved`; `external` means only that a copy names the namespace. `usages::libraries` charges every node visit and kept key before the scan, and a scan that runs out stops the build.

Library query (`workspace/library.rs`): `usages` with `workspaceId` and `library {kind, namespace, key}` (CLI: a workspace selector plus `--library K --namespace NS --key KEY`) reads that exact target in every visible source's published `scope` (`sourceId` narrows to one), sources in added order, then `(rid, seq)`. MCP refuses `file`, `node`, `resource`, `snapshotId`, `relation` and `direction`; a relocated CLI `--file` gets a workspaceId recovery. `definition` is always `{state: unresolved, reason: library_source_unproven}`. Each result carries `hidden`, `internal`, `page` and `scopeRoot` from the stored record and the generation's page/root lists, read once a source shows a use; no `path`, which would walk ancestors. A page holds 3 MiB of serialized results, so MCP's text and structuredContent copies fit its 8 MiB cap: each use is checked in UTF-8 bytes (`length(CAST(… AS BLOB))`) before it is copied and as serialized after; a later oversized use ends the page with a cursor, a first one is `response_budget_exceeded`. `coverage.sources` gives each source's path, state and nextSteps; reasons `source_not_ready`, `index_partial` (stopped build, unread fields or an unkept reference), `namespace_unknown` (the key with a null namespace), `hidden_excluded` (not incompleteness) and `authorization_restricted` (sources outside the roots, unnamed). Cursor `l1.<fingerprint>.<source>.<rid>.<seq>` binds the reference, scope, includeHidden, sourceId, versions, visibility and each source's state and generation; a change is `cursor_stale`.
