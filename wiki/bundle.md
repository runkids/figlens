# Design bundle

Load this to change the bundle zip, its manifest or `context.md`, batch bundles, the font inventory or `figlens verify`. Emitted node fields and the `.fig` format are in `fig-format`.

## Bundle and batch mode (2026-10-22)

- Bundles include [preflight](mcp.md#shared-sources-and-runtime-behavior).
- `context.md` includes website-image handoff guidance. Inspect the target project's actual image components, neighboring pages, asset conventions and framework/loader/CDN configuration first; applicable instructions and docs supplement that evidence. Reuse its established delivery pipeline. With no established approach, keep bundle originals as sources, retain pure vectors as SVG, and prepare bitmap/mixed assets as WebP at display dimensions × DPR (PNG for lossless needs; evaluate AVIF when useful). SVG exports may embed full-resolution images, so inspect content and bytes before using them as web icons. Use `scale` to request resolution and `maxSize` to cap the longest side; `quality`/`maxKb` control lossy encoding, not dimensions. Export a selected node to preserve crops, masks and effects; without the source `.fig`, optimize bundle assets through project tooling. Create output directories and inspect MCP `isError`/`content` before retrying. Check returned sizes, responsive delivery, reserved layout space, main-image priority and offscreen lazy loading. Verify desktop/mobile transferred bytes and visual quality, measure LCP/CLS when possible, and report missing checks. PNG's MCP compatibility recommendation is for inline references, not a website delivery default.
- `figlens bundle <file.fig> <node> <out.zip> [--file-key K] [--name N]` writes `manifest.json` (`format: "figlens-bundle"`, `version: 1`: producer, source file key and Figma URL, root paths, every file with role, media type, size and sha256), `design/nodes.json`, `design/variables.json`, `design/fonts.json`, `assets/` with `assets.json` and `missing-assets.json`, `references/screen.png` and `context.md` (how to build from the files). It prints `{nodeId, path, warnings}` on stdout: the warnings (missing assets and known render limitations; `missing-assets.json` contains only asset failures) go to stdout rather than stderr so MCP clients receive them. `export` likewise prints `{path, width, height, bytes, quality}`; `tree` stays indented text (1.6x smaller than JSON on Nucleus UI at depth 3) unless `--json`. Over MCP, `bundle` and `export` declare an `outputSchema` and return that object as `structuredContent`. `--name` sets `root.name` (default the node's name); `--file-key` sets `source.fileKey` (default: taken from a Figma URL node argument).
- `figlens bundle <file.fig> --frames <list> --out-dir <dir> [--file-key K] [--jobs N]`: decodes once and writes the bundle of each listed node id to `<dir>/<nodeId with : as ->.zip`, in parallel (default all cores), printing one JSON line per frame as it finishes: `{nodeId, path, warnings}` or `{nodeId, error}`. A frame's failure or panic is only its line; the exit status is nonzero only when the `.fig` or the list cannot be read. Bundles equal the single-frame command's except `createdAt` (72 of 72 zips checked). Historical timings are in [performance](performance.md#historical-batch-timings). `--jobs N` bounds concurrent frames (0 or omitted: all cores), not the rendering within each bundle. Frame workers and rayon use 8 MiB stacks; render assets and the reference rasterize in parallel and are added in plan order, so the zip is unchanged. `--jobs 1` runs frames sequentially while retaining inner rendering parallelism. Nucleus UI (172 frames, 12 cores): 35 s → 8.5 s with this and the filter-region fix; its largest frame 16391:2800 33.5 s → 5.9 s.

## Readiness check (2026-10-28)

A bundle proves its own integrity, not the project's readiness: it carries no font files, and only the running project can show whether faces load and assets deliver.

- `design/fonts.json` (`root.fonts` in the manifest, role `metadata`) lists `{faces: [{family, style, weight, postScriptName, nodeIds}]}`, one entry per family and style, from `bundle::fonts` over the emitted document. It covers visible text only (a hidden node skips its subtree), each node's own style when some character uses it (no overrides, override id 0, or fewer overrides than characters), and the `styleOverrideTable` entries that `characterStyleOverrides` actually applies, merged over the node style. Unused table entries are not faces.
- `figlens verify <bundle.zip|dir>` (MCP `verify` with `bundle`) reads a zip or its extracted directory and prints `{path, files: {verified, missing, changed, invalid}, missingAssets, fonts, unverified}`. Every manifest file is hashed against its size and sha256; `changed` carries expected and actual values; reading stops one byte past the declared size, so actual is null for a larger file, a directory or a link resolving outside the bundle. Manifest paths are untrusted: only plain relative paths are looked up, and other paths are listed under `invalid`. Files not in the manifest are ignored, so an agent may add its own. `missingAssets` repeats `missing-assets.json`. Fonts come from `design/nodes.json` through the same function, so bundles made before `design/fonts.json` existed also get an inventory; every face is `unverified`, and `unverified` names the browser checks left to the agent. JSON files over 256 MiB are refused. Each declared size is reserved from a 1 GiB hashing budget per bundle before reading, so total reads stay within it: a file whose declared size no longer fits is not read and is counted in `unverified`. A damaged `design/nodes.json` or `missing-assets.json`, already listed as changed, adds an `unverified` note instead of failing the report.
- The report never blocks: exit status 0 unless the bundle or its manifest cannot be read, or the manifest is not `figlens-bundle` version 1. Under MCP `--root`, `bundle` is admitted and rechecked like other paths, and the reply keeps the caller's path.
- Not done here: project or system font lookup, which needs font-file parsing and per-OS discovery, and browser checks (asset URLs, decoding, rendered size, `document.fonts.load`), which need the running project. Agent guidance for those is in `skills/figlens/SKILL.md` and `context.md`.
